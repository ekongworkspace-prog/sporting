# Turfing

Turfing is a football platform for players, clubs, coaches, referees, tournaments, fixtures, contracts and wallets.

## Applications

- `web/` - Next.js web application
- `api/` - Express and MongoDB API

## Local setup

Copy each application's `.env.example` file to `.env` and provide the required local configuration.

```bash
cd api
npm install
npm run dev
```

```bash
cd web
npm install
npm run dev
```
